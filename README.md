# 안양여고 AI 행정 업무와 에이전트

연수 주제: **AI 자동화 에이전트 구축 및 생산성 도구를 통한 행정 업무 효율화**

- 웹페이지: GitHub Pages 배포 주소는 Actions 배포 후 생성됩니다.
- 실습 자료: `practice/`
- 가상 브라우저 실습: `browser-lab.html`

## 가장 먼저
1. 저장소 전체를 ZIP으로 내려받습니다.
2. `practice/START-HERE.txt`를 읽습니다.
3. Antigravity에서 저장소 폴더를 프로젝트로 엽니다.
4. `AGENTS.md`와 `.agents/agents/`를 확인합니다.

실습 데이터는 모두 가상자료입니다.
